# Temp assets manifest — sourced gap-filler

Tracking required by `docs/art-pipeline.md` §8: sourced gap-filler looks
finished, so every sourced asset gets a row here when it enters the project
and loses it when final art replaces it. **Pre-ship gate: this table must be
empty.**

Two kinds of asset land here, and the licensing rule only applies to one:

- **Sourced third-party gap-filler** — Kenney (CC0) only, without explicit
  written approval (§7).
- **Stand-in art made in-house** (PixelLab, hand-drawn) — no licensing
  question, but it still gets a row: it looks finished, so it is exactly
  the kind of asset that ships by accident. Name the tool in the source
  column so it stays obvious what is temporary.

Block placeholders are tracked separately in `stand_ins.json`, generated by
`tools/make_placeholders.py`.

AssetRegistry parses rows whose first cell is a `res://` path and lists any
still present at startup in debug builds.
